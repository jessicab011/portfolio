# Portfólio Pessoal

Desenvolvido para apresentar minha trajetória na área de tecnologia, reunindo projetos, habilidades e experiências.

O objetivo deste projeto foi criar uma interface moderna, responsiva e organizada, aplicando boas práticas de HTML e CSS.
